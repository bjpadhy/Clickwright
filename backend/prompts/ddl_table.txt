# Rules
1. Table name = the event name exactly: `{{event}}`. ENGINE = MergeTree.
2. Columns = the flattened field names from the profile, exactly, minus the `event` field. Never drop a field; never invent one.
3. Types from the measured profile:
   - timestamps → DateTime64(3) · booleans → UInt8
   - integers: UInt8 if max < 256, UInt16 if max < 65536, else Int64; money/decimals → Float64
   - strings with measured distinct < 1000 → LowCardinality(String), EXCEPT identifiers (user_id, application_id, session/share ids, uuid-like) which stay String
   - fields with any null/empty rate → String DEFAULT '' (bucket empties at query time); Nullable only for numerics with no sensible default
4. ORDER BY starts with the join key — `application_id` when this event's profile shows it always present, else `user_id` (or the event's own entity id when neither exists) — then `timestamp`. PARTITION BY toYYYYMM(timestamp).
5. Every column gets a COMMENT of AT MOST 12 words — meaning plus the one gotcha that matters (units, currency, null semantics). No full sentences, no repetition of the column name. End with a table-level COMMENT of at most 20 words: the event, its funnel role, the spec that created it.
6. Exactly ONE `CREATE TABLE` statement. No DROP/ALTER/anything else. Escape single quotes inside comments by doubling them ('').
